路径说明

  1. 主路由保留上游 DHCP 和主 Wi-Fi。
  2. wan0 从主路由获取 192.168.100.x 地址。
  3. lan0 固定为 192.168.1.1/24，向下游提供 DHCP、DNS 和网关。
  4. AP「rp5」工作在桥接/AP 模式，不运行第二个 DHCP。
  5. wlan0 只用于 SSH 和故障回滚，不作为透明代理入口。
