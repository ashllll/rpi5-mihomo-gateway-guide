## 已核对且成立的关键结论

1. 五子类分类法与成员（含 UX7 同时出现在 wifi-integrated 与 whole-home-wifi）：techspecs 分类页 `subCategoriesWithProducts` 实测与 01:5 一致。
2. 三款 compact 的吞吐与端口：Max 2.3 Gbps / 5×2.5GbE，Ultra 1 Gbps / 1×2.5GbE+4×1GbE 且应用套件仅 Network，Fiber 5 Gbps / 4×2.5GbE+1×10GbE+2×10G SFP+ 且 30W PoE。
3. UCG-Max 关键规格：默认 WAN 1、最大 WAN 4、MAC 2000、四核 A53 1.5GHz、3GB、16.1W、55 BTU/hr、-10~40℃、5×2.5GbE。
4. NVR 存储四档与官方注释原文（No Storage 不含盘、第三方盘需托盘、512 GB 与 1/2 TB 含托盘与盘）；托盘支持 2230–22110，UCG-Max 每块 NVMe 为 PCIe Gen3x2。
5. 商店价格与状态：$279 / $199（NS 售罄，restock 2026-11-06）、€250 / €179、£220 / £159；UACC-SSD-1TB $390、2TB $730 均售罄，托盘 $19 有货；1 TB/2 TB 无独立 techspecs 页（重定向至分类首页）。
6. Network API 共 44 条路径、73 个操作，tag 计数为 Firewall 13、UniFi Devices 8、Supporting Resources 8、ACL 7、Networks 6、Switching 6，其余 5/5/5/5/3/1/1。
7. 分页：23 个带 `limit` 的 GET 中 22 个默认 25、上限 200，唯一例外 hotspot vouchers 默认 100、上限 1000。
8. 22 个 POST/PUT/PATCH 的 `requestBody.required` 全为 true；`PATCH` 仅存在于防火墙策略更新；ACL 与防火墙策略各有 `ordering` 的 GET/PUT。
9. Site Manager API 为 10 条路径、14 个操作（5 条 connector 透传 + 9 条业务接口），安全方案 `apiKey / header / X-API-Key`，server 为 `https://api.ui.com`。
10. 限流只在 Site Manager 文档给出：EA 100 次/分、v1 10,000 次/分，超限 429 + `Retry-After`（规范示例值 5）；Network 规范无 429 定义。
11. 错误体：Network 为 7 字段（含 `requestId`、`requestPath`、`statusName`），Site Manager 为 4 字段（`code`/`httpStatusCode`/`message`/`traceId`）并列 7 个常见码。
12. 03 章三条 filter 示例均被端点支持：设备端点 `name` 含 `like`、`firmwareVersion` 含 `lt`（及 isNull…notIn），客户端端点有 `access.type`、`access.authorized`，`and(...)` 逻辑写法与 Filtering 页一致。
