# ADR-0001：机制代码与私有部署数据分离

[ADR 索引](README.md) · [Wiki 首页](../README.md)

项目需要可公开复现，又必须保护订阅、节点凭据、管理密钥与个人网络配置。
采用机制源码、虚构参数与空能力池发布；实际部署输入和生成结果仅保存在私有环境。
本记录是对现有行为的补录，不授权发布任何部署端文件。

## 替代方案

完整复制设备配置最容易复现一次安装，但会泄露凭据，也会把站点参数和代码绑定。
只发布教程不发布机制则难以测试更新和回滚。当前选择同时提供源码与不含真实数据的模板。

## 后果

- renderer 生成新 secret，拒绝覆盖已有输出；候选本身仍是私密数据。
- automation 安装器覆盖机制脚本/单元，已有部署数据保留；配置升级需要人工合并。
- `.gitignore` 不是秘密扫描，也不能移除已经进入历史的凭据。
- 不发布个人备份、日志、镜像和包含凭据的产物；提交前扫描工作区及历史。
