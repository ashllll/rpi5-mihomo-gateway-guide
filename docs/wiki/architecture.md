## 系统边界

网关有两个职责不同的平面：数据平面负责 DNS、分流、透明转发；维护平面负责生成候选、
验证、备份、更新和观测。生产参考允许 HA 等本地服务共存，但不是它们的安装器，
也不提供访客网络隔离、账号解锁或吞吐保证。

本页区分三条入口，详细拓扑见[架构参考](../current-architecture.zh-CN.md)。

| 模块 | 职责 | 不应承担 |
|---|---|---|
| 上游路由器 | 提供上联网络及地址 | 透明代理选路决策 |
| dnsmasq | DHCP 和 DNS 入口 | 第二份代理规则或 fake-IP 映射 |
| MosDNS（生产参考可选层） | DNS 分类与路由数据、回退 | 替代 Mihomo 的代理出站与 fake-IP 真值 |
| Mihomo | 代理协议、TUN/auto-redirect、规则、DNS/fake-IP、原生组健康检查 | 推断所有供应商商业授权或账号状态 |
| nftables | 受管基础过滤与 NAT | 清空核心动态表、固定猜测 redirect 端口 |
| 自动化层 | 维护候选、互斥、评分及有界恢复 | 每次单业务失败全局重启 |

## DNS 与连接不是同一条证据链

一键入口和手动生成器基线：客户端 DNS → dnsmasq → Mihomo DNS。
生产参考：客户端 DNS → dnsmasq → MosDNS → 国内解析 / Mihomo DNS。
后者需要另行准备规则数据并验证，不能从生成器运行成功推断已经安装。

域名获得 fake-IP 后，还要经过客户端默认路由、LAN 防火墙、动态 redirect/TUN、规则命中和出站节点。
显式代理请求绕过了部分透明入口，因此不能代替真实 LAN 验收。
DNS 回退到直连仅有助于基础解析，不保证被屏蔽的海外服务仍可访问。

## 三条配置生成链

| 路径 | 输入到运行结果 | 关键约束 |
|---|---|---|
| 一键 | 检测网络 + defaults + 私有订阅 → 临时核心解析 → 候选验证 → 备份/恢复计时器 → 激活/门禁 | 独立服务和目录；只导入节点，规则来自项目默认配置 |
| 手动 | 站点 JSON → `render()` → 私有候选目录 | 不安装；占位 provider 必须替换 |
| 自动化 | 主/额外订阅 + 本地保留节点 + manifest → candidate/overlay → 验证 → 备份 → 加载/门禁 | 与一键入口不同，不可盲目交叉覆盖 |

## 策略优先级与供应商能力

生产 overlay 在已有规则前添加私网/国内/游戏直连、下载及服务规则，并去重保留其余字符串规则，
但会明确过滤所有 `PROCESS-` 开头的规则。迁移时必须核对进程级例外，不能认为它们仍在生效；
它会替换受管业务组的定义，不是“完整原样采用供应商配置”。源订阅与运行候选应分开保存。
一键入口完全使用另一套默认策略。相关取舍见 [ADR-0003](../adr/0003-capability-policy.md)。

AI、浏览/媒体和下载使用不同池。STT / ByWave 的下载许可属于本部署确认的前提；
普通 GLaDOS 节点不能默认进入下载池。正则、标签和 allowlist 只是部署者输入，不是供应商授权查询接口。
当前源码还存在兼容旧来源的名称处理，不能把“不在下载池”理解成“订阅已从所有本地位置清理”。

HTTPS 中同一主机可能同时承载聊天和大文件；域名规则无法精确识别全部下载或所有游戏进程。
`git clone` 与 GitHub 页面可能共用主机，专用下载域名不能覆盖全部 Git pack 流量。

## 观测、选择与执行

- 原生组：fallback 按候选顺序找可用节点，url-test 按探测延迟选择，load-balance 分配新连接。
- 分类检查：分钟级检测实际出口路径，故障按组复测；API 与站点限制分开记录。
- 影子评分：采样 per-URL 健康和延迟，维护 EWMA、失败与冷却，不直接切组。
- 隔离执行：可选 timer，受候选保底及验证门禁控制；默认不启用。

当前不是“全业务、多路径、吞吐与会话质量共同优化”的调度器。X 多路径检测也没有把 CDN 结果
直接合成为每个候选节点的资格分数；原生选择主要依据配置的单个 API 探针。
详情见[智能选择](../adaptive-selection.zh-CN.md)及[路线图](roadmap.md)。

## 故障边界

| 故障 | 当前机制 / 操作 | 保留的限制 |
|---|---|---|
| 单业务不可用 | 分类记录、对应组复测 | 不能迁移旧连接；不保证一定换到可用平台出口 |
| 核心进程退出 | systemd 和检查脚本有恢复机制 | 上游、配置或系统故障仍可能阻止恢复 |
| 候选更新失败 | 验证门禁与回滚 | 回滚也可能失败，需私有备份及独立管理通道 |
| DNS 路由异常 | 候选验证、模式回退 | 直连 DNS 不是代理可用性保底 |
| LAN 动态入口被拦 | 保留核心表，可信 LAN 基线 | 无不可信客户端隔离能力 |

本页说明源码机制，不是当前机器的巡检结果。验收见[验证矩阵](validation.md)。
