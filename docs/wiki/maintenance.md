# 维护与文档同步

[Wiki 首页](../README.md) · [运维](../operations.zh-CN.md) · [ADR](../adr/README.md)

## 信息放在哪

| 内容 | 位置 |
|---|---|
| 这台机器在跑什么 | 根 `README.md` |
| 机制、判据、状态字段 | [架构](../architecture.zh-CN.md)、[运维](../operations.zh-CN.md) |
| 安装顺序 | [部署](../deployment.zh-CN.md) |
| 高成本取舍 | [`docs/adr/`](../adr/README.md)，改变时新增 ADR 而不是改写历史 |
| 术语 | 根 `GLOSSARY.md` |
| 外部项目调研 | [`docs/research/`](../research/)，开头标明“非本仓库交付” |
| 订阅、节点、密钥、真实网络清单 | 部署端私有记录，不进仓库、Wiki、截图或日志 |

不要在多处复制同一张参数表：配置以仓库模板为准，现场值以私有文件为准。

## 改动的最小闭环

1. 阅读改动涉及的脚本、单元与文档，确认它们描述的是同一台机器。
2. 改机制就同步架构/运维；改安装顺序就同步部署；两者都改才动 README 的栈表。
3. 运行受影响的 `tools/check_*.py` 与 `validate_public.py`，并在提交说明里写清
   本地通过、未部署、未做真实客户端验收的边界。
4. 文档里的路径必须存在；删除或移动文件时同时清理引用。

## 证据记录模板

```text
日期 / 源码提交 / 核心版本：
改动范围与未改动范围：
执行的命令与结果摘要：
证据层（离线检查 / 启动门禁 / 出口抽样 / 真实 LAN / 真实业务）：
未执行项与已知限制：
备份位置与回滚办法（私有记录）：
```

文档不是监控。一次现场验证要带日期，不能长期当作“当前健康”。
