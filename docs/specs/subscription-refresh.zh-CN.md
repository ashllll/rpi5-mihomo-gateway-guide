# 自动订阅刷新

树莓派在开机十分钟后检查已配置的主订阅及未标记为手动的额外订阅，每次任务结束后等待 48 小时再次检查。成功、失败及无变化退出均开始下一轮等待；重启后重新执行开机检查。超过开机十分钟时首次启动 timer，会立即触发检查。

复用 `mihomo-subscription-update.service` 的候选校验、维护锁、事务备份、业务检查及失败恢复。有效节点没有变化时不重启核心；有变化时现有更新程序会重启核心，连接可能短暂中断。下载失败的来源保留当前主节点或最后可用额外订阅缓存，不将其报告为已刷新。

安装器启用订阅 timer，后续升级不得将它重新禁用。部署者在私有地址与配置准备好后启动 timer；地址失效需提供新的有效地址，任务不会猜测订阅凭据。

验收接口：systemd timer 配置与实际调度回读、安装器启停清单、订阅 CLI 的候选生成及失败恢复、实机订阅与运行节点比对、真实客户端业务访问。配置测试不替代运行验收。

`MIHOMO_SUBSCRIPTION_MANUAL_SOURCES` 是空格分隔的额外来源标识。手动来源不发起 URL 下载请求，合并时保留已校验缓存；对应的 `subscriptions.d/<来源>.url` 仍须保留以登记来源。缺失或损坏缓存则在安装候选前停止，保留当前配置。`--force` 不覆盖这项来源策略。手动更新新节点需完成候选及业务验收后更新配置与缓存。
