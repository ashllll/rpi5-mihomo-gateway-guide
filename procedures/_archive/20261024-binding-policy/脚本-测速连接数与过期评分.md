# 脚本-测速连接数与过期评分

> **触发**：连接数超限；探测入口叠加；分账绕过；旧评分继承。
> **验证**：匿名回放覆盖预算/TTL/冷却；真实核心仅限 only-lo namespace；线上状态另读。

## 首选

## 被挡时

本机无核心时，在目标机 `unshare -n` 内用匿名回环代理；以命名空间内 `ip -j link` 只有 lo、路由为空证明隔离。
核心 API 就绪不代表组已加载；等待目标组出现。健康检查有一秒合并窗，恢复预算服务后等待下次有效检查。

## 别再来

| 弯路 | 为什么不通 |
| --- | --- |
| interval=0 关闭自动组 | 自动组回落 300 秒；暂停转 select 并关 provider 检测 |
| 仅外部定时任务扣费 | 启动/周期/业务故障会在核心发检测；URLTest 必须先申请同账预算 |
| 样本/observe 另指定账本 | 发起前核对 core/socket/config/measurement/ledger，worker 再核对 |
| 只比较 resolve 后的路径 | replace 原 alias 会拆账；锁/读/写均使用规范路径 |
| JSON 可解析就信任账本 | 负数与 NaN 会绕过判断；非法语义拒绝，不能重置账本 |
| TTL 重建所有状态 | 丢冷却升级；只清旧证据，保留隔离和恢复门槛 |
| 加锁前获取预算时间 | 并发倒序被误判回拨；锁后取时，过期请求不发起 |
| 回调内断言验证回滚 | 断言可能被故障处理捕获；记录结果，回调外断言 |

## 注意

预算拒绝不写失败健康历史；失联或丢响应不退款。原生新模式逐次扣费，旧 quality-only 仍预留整池回滚费用，不能混称同一种模式。
本账限制测量 HTTP 尝试，不是业务 TCP 总连接硬上限。离线通过不授权部署/启用 timer。
