## 契约

- 每次原生检测预扣 2 额度；保留 `/var/lib/mihomo-measurements/quality-budget.json`、`quality_attempts_per_hour`、账户键及有效历史。锁内复验本地策略，不调 RPC；仅接受映射叶节点及地址。拒绝准入不改路由或健康。
- 相同轻量 URL、期望状态与周期共用一个检查所有者。下载节点必须获准；AI/X/NF 不因订阅而进入下载池。
- 撤空下载授权时，旧受管子组保留为 `select: [REJECT]`，使旧引用明确拒绝。AI 重建按本组有序 filter 恢复当前叶节点；不可拿共享 provider 全量补池。冲突的 stability 类型覆盖须先移除，再使用全局暂停开关。
- 原生组需保留 provider 的 `expected-status`：核心只继承 URL，删掉状态码会使 fallback 手动复验接受任意响应。用失败→复验仍失败→恢复成功验证，三次检测均扣预算。
- `install_default` 保留私有清单；`route-defaults.yaml` 提供默认表。缺表、null、{} 继承默认；旧 profile 域名迁入，同 ID 显式项优先，空 domains 拒绝。
- 退役 quality provider 须同时匹配内建/旧 profile ID、file 类型、payload 旧 canonical hash 路径；先重建业务组，再删无引用 owner。仅按前缀删除会误伤用户 provider。
- 回归旧清单、中文节点换端口、角色/账户保留、provider 清理和暂停/启用重入；失败时保留候选及日志，勿用线上测速排错。

不要把额度拒绝当节点故障或业务健康；原生传输检查不等于平台登录或播放验收。
