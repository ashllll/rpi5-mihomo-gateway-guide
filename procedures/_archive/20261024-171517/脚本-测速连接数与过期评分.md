# 原生检测预算与路由迁移

> **触发**：原生 URLTest、预算拒绝、旧私有清单升级或退役 quality provider。  
> **验证**：仅离线合成回归；不代表设备已部署。不要用真实节点、公网探测或线上 timer 验证。

## 检查

```sh
python3 tools/check_overlay.py
python3 tools/check_automation.py
python3 tools/check_measurement_policy.py
python3 tools/check_native_budget.py
python3 tools/check_stability.py
python3 tools/check_subscription_candidate.py
```

## 契约

- 原生检测每次预扣 2 次额度；沿用 `/var/lib/mihomo-measurements/quality-budget.json` 与 `quality_attempts_per_hour`，保留账户键和未过期历史。锁内重读配置/策略但不调 HTTP；仅接受已映射叶节点与地址端口。失联、超额或未知身份只拒绝检测，不改路由和健康历史。
- 相同轻量 URL、期望状态与周期共用一个检查所有者。下载节点必须获准；AI/X/NF 不因订阅而进入下载池。
- `install_default` 保留旧私有 `capabilities.yaml`；公共下载/视频表由独立 `route-defaults.yaml` 安装。缺表、YAML `null` 或 `{}` 继承默认；旧 `download_quality.profiles` 的业务组和域名迁入，显式同 ID 项优先替换；空 `domains` 拒绝生成。
- 仅当 `quality-<profile>` 的 ID 在公共内建表或旧 profile 中、`type:file`，且 payload 的旧 ensure-ascii canonical hash 与路径一致，才认定生成器所有。先重建业务组，再删无引用 provider；不得按 `quality-` 前缀清扫。
- 回归覆盖旧无新表清单、私有角色/账户不变、中文叶节点换端口成功、旧启用与暂停 provider 均清理、无旧引用/探针且无关 provider 保留。

不要把额度拒绝当节点故障或业务健康；原生传输检查不等于平台登录或播放验收。
