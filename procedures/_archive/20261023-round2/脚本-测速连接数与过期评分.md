# 脚本-测速连接数与过期评分

> **触发**：机场连接数超限；测速入口叠加；单次失败切换；旧评分继承。
> **验证**：默认暂停生成无自动检测；匿名重放覆盖恢复/TTL/撤销；线上 timer 状态另行回读。

## 首选

```sh
python3 tools/check_measurement_policy.py
python3 tools/check_scoring.py
python3 tools/check_stability.py
```

## 被挡时

- 本机无核心时，在目标机 `unshare -n` 内使用匿名配置和回环假节点；先核对 `ip -j link` 只有 lo、路由为空，再做语法/只读 API 验证。
- 核心 API 启动早期可能已响应但组尚未加载；等待目标组出现再断言成员。

## 别再来

| 弯路 | 为什么不通 |
| --- | --- |
| interval=0 关闭自动组 | v1.19.28 自动组会回落 300 秒；暂停改 select 并关闭 provider 检测 |
| 只看缓存 success_samples | 没有新观察时旧计数不减少；按当前时刻重算 TTL 窗口 |
| 暂停时从旧 owner 恢复成员 | 旧 payload 可能已撤销；只保留当前定义并拒绝空池 |
| 使用 /sys/class/net 证明 netns 隔离 | 宿主 sysfs 挂载可能仍显示原接口；使用命名空间内 ip link/route |

## 注意

- 影子评分读快照，进程健康检查不发业务探针。质量 HTTP 尝试额度、原生名义计划都不是账户总 TCP 连接数上限。
- 离线通过不授权部署或恢复 timer；真实速度、账号限速解除及长时间会话必须单独验收。
