# 网关-配置安装断电窗口

> **触发**：手工改 `/etc/mihomo/config.yaml` 时 SSH 断了/机器掉电；重启后 mihomo 起不来，全家断网。
> **验证**：`sha256sum /etc/mihomo/config.yaml` 等于候选或旧文件之一；`curl --fail -H "Authorization: Bearer <secret>" http://127.0.0.1:9090/version` 返回 200 且带 version。

## 首选

```sh
sudo /usr/local/sbin/mihomo-config-install /path/to/candidate.yaml   # 先 --dry-run
```

同目录临时文件 → `fsync` → `rename` → `fsync` 目录；备份 0600 且 fsync；reload/restart 后真 API 门禁；任一步失败原子还原并再验 API。

## 被挡时

看到 `ROLLBACK FAILED: ...`：先按原因处理（备份不可读 / 服务起不来 / API 仍坏），不要重复安装；保留 `config.yaml.bak-*` 现场。

## 别再来

| 弯路 | 为什么不通 |
| --- | --- |
| `cp`/`install` 直接覆盖 live | 断电留半截文件，开机没有回退者 |
| 只查 `systemctl is-active` | 配置解析失败但旧进程仍在时，会误报成功 |
| 回滚失败仍打印 rolled back | 下一个人会以为已经恢复；必须非 0 且打印原因 |
| 把 secret 放进 curl 参数 | `ps` 可见；用 stdin 喂 header |

## 注意

- 原子性只覆盖「旧完整」或「新完整」；它不替代 `mihomo -t` 和 API 门禁。
- 实机演练：在维护窗口用 `MIHOMO_INSTALL_FAULT=kill-before-rename` 跑一次，确认 live 未变；这是测试钩子，生产不要设置。

证据：F-23 提交；`tools/check_config_install.py`。
